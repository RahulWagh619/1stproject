A responsive personal portfolio website built using **HTML**, **CSS**, and **JavaScript** to showcase my projects, technical skills, and achievements. The website features a modern design with support for both **Light** and **Dark** themes for an improved user experience.

---

# ✨ Features

- 🌗 Light/Dark mode toggle
- 📱 Fully responsive design
- ⚡ Smooth scrolling and animations
- 💼 Project showcase section
- 👨‍💻 About Me section
- 📧 Contact section
- 🎨 Clean and modern UI

---

# 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
